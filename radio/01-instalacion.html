1. Instalación del RTL-SDR Blog V4L en Windows

Fuentes oficiales: rtl-sdr.com/QSG, rtl-sdr.com/V4L, rtl-sdr.com/DIPOLE

Estado al 2026-10-02: instalado y verificado. Zadig aplicado, rtl_test detecta Blog V4L / RTL-SDR Blog V4 Lite Detected, y SDR# recibe FM.

Qué hay en esta carpeta

Ruta Contenido
drivers\rtlsdrblog-V1.4.0\ Driver oficial RTL-SDR Blog V1.4.0 (soporta V4/V4L), x86 y x64, más las herramientas rtl_*.exe
sdrsharp\ SDR# x86 (Airspy) con el rtlsdr.dll x86 del V1.4.0
sdrpp\sdrpp_windows_x64\ SDR++ nightly con el rtlsdr.dll x64 del V1.4.0 (el original quedó como rtlsdr.dll.sdrpp-original)
zadig-2.9.exe Zadig, firmado por Akeo Consulting. Instala el driver USB WinUSB
downloads\ Los zips originales descargados
tools\ Scripts propios: pasos de satélites, grabación, análisis y gráficos

Requisitos que ya están instalados en el PC: Visual C++ Redistributable x86/x64 y .NET 8 Desktop Runtime x86, que necesita SDR#.

Paso 1: driver USB con Zadig (solo una vez, ya hecho)

Solo hay que repetirlo si conectas el dongle en otro PC o si Windows reinstala el driver.

  1. Conecta el V4L. Clic derecho en zadig-2.9.exe → Ejecutar como administrador.
  2. Menú Options → List All Devices. Si no aparece el dispositivo, desmarca también Ignore Hubs or Composite Parents.
  3. En la lista elige Bulk-In, Interface (Interface 0). - Comprueba que el USB ID sea 0BDA 2838 00. - No elijas ningún otro dispositivo: le sobrescribirías el driver (teclado, ratón, red...).
  4. A la derecha de la flecha verde debe aparecer WinUSB.
  5. Pulsa Replace Driver (o Install Driver) y espera a que termine.

Paso 2: comprobar el dongle

Cierra antes SDR# y SDR++. Solo un programa puede usar el dongle a la vez. Si hay otro abierto, verás usb_open error -3 (el mensaje sobre "udev rules" es para Linux y no aplica).

drivers/rtlsdrblog-V1.4.0/x64/rtl_test.exe -t

Salida esperada:

  0:  RTLSDRBlog, Blog V4L, SN: 00000001
Found Rafael Micro R820T tuner
RTL-SDR Blog V4 Lite Detected
No E4000 tuner found, aborting.     <- normal: -t solo sirve para tuners E4000

El V4L usa el tuner R820T, a diferencia del V4, que usa el R828D. Por eso SDR# muestra "R820T".

Paso 3: escuchar

  • SDR#: sdrsharp\SDRSharp.dotnet8.exe → Source: RTL-SDR USB → Play.
  • SDR++: sdrpp\sdrpp_windows_x64\sdrpp.exe → Source: RTL-SDR → Play.
  • Prueba rápida: FM comercial (88–108 MHz) en modo WFM, bandwidth 200 kHz.
  • Ganancia: en Santiago las FM son muy fuertes, así que empieza con RF Gain bajo (0–15 dB). Si al subirla el piso de ruido sube todo junto o aparecen señales "fantasma", el dongle se está saturando. Ver 02-barrido-fm.md.
  • Ancho visible: hasta 2.4 MSPS ≈ 2.4 MHz estable. Lo útil son unos 2 MHz centrales.
  • HF: el V4L no necesita direct sampling, basta con sintonizar la frecuencia.
  • HDSDR/SDRuno: usa el ExtIO de github.com/rtlsdrblog/ExtIO_RTL/releases y desactiva IF AGC.
  • Bias tee (4.5 V, LED rojo): déjalo apagado. Solo se usa con LNA o antenas activas.

Antena dipolo

  • Longitud: más larga = frecuencias más bajas. Hay unos 2 cm de metal dentro de la base que también cuentan.
  • Grande, 5 secciones ≈ 70 MHz · grande, 1 sección ≈ 285 MHz
  • Pequeña, 4 secciones ≈ 445 MHz · pequeña, 1 sección ≈ 1030 MHz
  • Señales terrestres (FM, aviación, radioaficionados): dipolo vertical, con el elemento del vivo del coaxial hacia arriba.
  • Satélites a 137 MHz (Meteor): V horizontal a unos 120°, con cada elemento de unos 53.4 cm. Ver 03-satelites.md.
  • Ubicación: usa el cable de extensión de 3 m para alejar la antena del PC (ruido) y ponerla en una ventana o al exterior.

Actualizar el driver en el futuro

  1. Revisa github.com/rtlsdrblog/rtl-sdr-blog/releases y baja Release.zip.
  2. Copia x86\rtlsdr.dll en sdrsharp\ y x64\rtlsdr.dll en sdrpp\sdrpp_windows_x64\.
  3. Zadig no hace falta repetirlo.
