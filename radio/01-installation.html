1. Setting up the RTL-SDR Blog V4L on Windows

Official sources: rtl-sdr.com/QSG, rtl-sdr.com/V4L, rtl-sdr.com/DIPOLE

Status as of 2026-10-02: installed and verified. Zadig applied, rtl_test detects Blog V4L / RTL-SDR Blog V4 Lite Detected, and SDR# receives FM.

What is in this folder

Path Contents
drivers\rtlsdrblog-V1.4.0\ Official RTL-SDR Blog driver V1.4.0 (supports V4/V4L), x86 and x64, plus the rtl_*.exe tools
sdrsharp\ SDR# x86 (Airspy) with the x86 rtlsdr.dll from V1.4.0
sdrpp\sdrpp_windows_x64\ SDR++ nightly with the x64 rtlsdr.dll from V1.4.0 (the original was kept as rtlsdr.dll.sdrpp-original)
zadig-2.9.exe Zadig, signed by Akeo Consulting. Installs the WinUSB driver
downloads\ The original downloaded zip files
tools\ My own scripts: satellite passes, recording, analysis and plots

Prerequisites already installed on the PC: Visual C++ Redistributable x86/x64 and the .NET 8 Desktop Runtime x86, which SDR# needs.

Step 1: USB driver with Zadig (only once, already done)

You only need to repeat this if you plug the dongle into another PC or Windows reinstalls the driver.

  1. Plug in the V4L. Right-click zadig-2.9.exe → Run as administrator.
  2. Menu Options → List All Devices. If the device does not appear, also uncheck Ignore Hubs or Composite Parents.
  3. In the list, choose Bulk-In, Interface (Interface 0).
    • Check that the USB ID is 0BDA 2838 00.
    • Do not choose any other device: you would overwrite its driver (keyboard, mouse, network...).
  4. WinUSB must appear to the right of the green arrow.
  5. Click Replace Driver (or Install Driver) and wait for it to finish.

Step 2: check the dongle

Close SDR# and SDR++ first. Only one program can use the dongle at a time. If another one is open, you will see usb_open error -3 (the message about "udev rules" is for Linux and does not apply).

drivers/rtlsdrblog-V1.4.0/x64/rtl_test.exe -t

Expected output:

  0:  RTLSDRBlog, Blog V4L, SN: 00000001
Found Rafael Micro R820T tuner
RTL-SDR Blog V4 Lite Detected
No E4000 tuner found, aborting.     <- normal: -t only works with E4000 tuners

The V4L uses the R820T tuner, unlike the V4, which uses the R828D. That is why SDR# shows "R820T".

Step 3: listen

  • SDR#: sdrsharp\SDRSharp.dotnet8.exe → Source: RTL-SDR USB → Play.
  • SDR++: sdrpp\sdrpp_windows_x64\sdrpp.exe → Source: RTL-SDR → Play.
  • Quick test: commercial FM (88–108 MHz) in WFM mode, 200 kHz bandwidth.
  • Gain: FM stations in Santiago are very strong, so start with a low RF Gain (0–15 dB). If raising it lifts the whole noise floor or "ghost" signals appear, the dongle is overloading. See Wideband sweeps with rtl_power.
  • Visible span: up to 2.4 MSPS ≈ 2.4 MHz is stable. The useful part is the central ~2 MHz.
  • HF: the V4L does not need direct sampling; just tune to the frequency.
  • HDSDR/SDRuno: use the ExtIO from github.com/rtlsdrblog/ExtIO_RTL/releases and turn off IF AGC.
  • Bias tee (4.5 V, red LED): leave it off. It is only for LNAs or active antennas.

Dipole antenna

  • Length: longer = lower frequencies. About 2 cm of metal inside the base also counts.
    • Large, 5 sections ≈ 70 MHz · large, 1 section ≈ 285 MHz
    • Small, 4 sections ≈ 445 MHz · small, 1 section ≈ 1030 MHz
  • Terrestrial signals (FM, aviation, amateur radio): vertical dipole, with the coax center-conductor element pointing up.
  • 137 MHz satellites (Meteor): horizontal V at about 120°, with each element about 53.4 cm long. See Satellites.
  • Placement: use the 3 m extension cable to move the antenna away from the PC (noise) and put it in a window or outdoors.

Updating the driver in the future

  1. Check github.com/rtlsdrblog/rtl-sdr-blog/releases and download Release.zip.
  2. Copy x86\rtlsdr.dll into sdrsharp\ and x64\rtlsdr.dll into sdrpp\sdrpp_windows_x64\.
  3. There is no need to run Zadig again.
